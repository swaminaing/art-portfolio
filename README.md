# Artful Portfolio

A colourful, responsive, single-page portfolio built with React, TypeScript, Vite, and component-based UI.

## Run locally

1. Install [Node.js](https://nodejs.org/) if you haven't already.
2. Extract this project and open its folder in a terminal.
3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL printed by Vite, usually `http://localhost:5173`.

## Personalise it

- In `src/App.tsx`, replace **Alex Morgan**, the introduction, and the about text with your own details.
- Change `hello@example.com` to your email address.
- Replace the GitHub, Instagram, and Dribbble URLs with your own profile links.
- In `index.html`, update the page title and description.
- In `src/styles.css`, adjust the CSS colour variables near the top to change the palette.

## What's included

- Single page with Hero, About, Contact, and footer sections
- Reusable `Header`, `Hero`, `About`, `Contact`, `Footer`, and `SocialLink` components
- Responsive layout for desktop and mobile
- Decorative artwork built with CSS shapes (no image assets required)
- Google Fonts: DM Sans, DM Mono, and Playfair Display
- Smooth anchor navigation and reduced-motion support

Google Fonts requires an internet connection; the site still uses fallback fonts if unavailable.
